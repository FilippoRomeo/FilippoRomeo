## Selected public work

### [Responsively Sessions](https://github.com/FilippoRomeo/responsively-app)
A maintained fork of Responsively App focused on persistent, isolated browser Sessions and MCP-driven development workflows. Adds per-project browser profiles, session lifecycle tooling, a native macOS launcher, validation gates, and safer destructive actions.

### [Agent Response History](https://github.com/FilippoRomeo/agent-response-history)
A local macOS tool for listing, copying, storing, and reusing assistant replies from Claude Code and Codex sessions. Designed around local transcript parsing, privacy, reversible installation, and zero-network operation.

### [Poetformer](https://github.com/FilippoRomeo/poetformer)
A poetry-generation experiment comparing base Mistral 7B output with a LoRA fine-tuned model trained on public-domain poetry, using PyTorch, Hugging Face Transformers, PEFT, and Streamlit.

### [Image Captioning Transformer](https://github.com/FilippoRomeo/Image-Captioning-Transformer)
A PyTorch image-captioning system with ViT or CLIP image encoders, a Transformer decoder, SentencePiece or Hugging Face tokenization, Flickr30k training, and an inference pipeline.

### [Archetype Analysis Drawing](https://github.com/FilippoRomeo/archetype-analysis-drawing-blog)
Creative-computing research combining pose estimation, computer vision, Jetson hardware, Arduino, servos, solenoids, laser positioning, and robotic drawing.

### [DirtySprayPaint](https://github.com/FilippoRomeo/dirtySprayPaint)
A physical-computing spray-paint machine using a compressor, solenoid, pressurised paint system, pan-tilt mechanism, laser aiming, and joystick control.
